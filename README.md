# Hola, soy Andejecruher 👋

**Full Stack Developer | Laravel • Python • Node.js • React | AI Agents & Automation | SaaS Multi-Tenant | Messaging Integrations | Docker • CI/CD • DevOps Learning Path**

Soy desarrollador Full Stack enfocado en la construcción de plataformas SaaS escalables, automatización de procesos e integración de inteligencia artificial en productos digitales.

Trabajo principalmente en sistemas backend, APIs, aplicaciones web modernas e integraciones con canales de comunicación como **WhatsApp, Instagram, Facebook y Telegram**. Me interesa crear soluciones que conecten tecnología, datos y automatización para resolver problemas reales de negocio.

Actualmente estoy fortaleciendo mi camino hacia **DevOps, infraestructura cloud, CI/CD, Docker, monitoreo y arquitecturas más resilientes**.

## Sobre mí

Soy desarrollador **Full Stack** enfocado en la construcción de plataformas **SaaS escalables**, automatización de procesos e integración de **inteligencia artificial** en productos digitales.

Trabajo principalmente en sistemas backend, APIs, aplicaciones web modernas e integraciones con canales de comunicación como **WhatsApp, Instagram, Facebook y Telegram**.

Mi stack principal combina **JavaScript, PHP y Python**, utilizando tecnologías como **Laravel, Node.js, Express, FastAPI y React** para construir APIs, servicios backend y aplicaciones web modernas.

Actualmente estoy fortaleciendo mi camino hacia **DevOps, cloud infrastructure, CI/CD, Docker, monitoreo de servicios y arquitecturas más resilientes**.
